# PDFs

Upload PDF documents and extract editable LaTeX. Supports both text-based and scanned PDFs (scanned PDFs go through an additional OCR step). Maximum file size: 50 MB, 100 pages.

## Overview

The PDF extraction workflow is a two-step process: first upload a file with `POST /pdfs`, then trigger extraction with `POST /pdfs/:id/process`. List endpoints return paginated responses with `data` and `meta` fields. Pass `?page=1&limit=50` as query parameters to control pagination. Scanned PDFs may take longer to process due to the OCR step.

---

### POST /pdfs

Upload a PDF for LaTeX extraction. Accepts files up to 50 MB and 100 pages. The file is stored and queued for processing.

**Auth:** Bearer token or API key

```bash
curl -X POST https://api.texer.org/pdfs \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "pdf=@paper.pdf"
```

```json
{
  "id": "pdf_m3k7w1",
  "filename": "paper.pdf",
  "pages": 12,
  "status": "uploaded",
  "created_at": "2025-06-15T09:10:00Z"
}
```

---

### GET /pdfs

List all uploaded PDFs for the authenticated user. Results are paginated.

**Auth:** Bearer token or API key

```bash
curl https://api.texer.org/pdfs \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```json
{
  "data": [
    {
      "id": "pdf_m3k7w1",
      "filename": "paper.pdf",
      "pages": 12,
      "status": "processed",
      "created_at": "2025-06-15T09:10:00Z"
    }
  ],
  "meta": { "page": 1, "limit": 50, "total": 1, "totalPages": 1, "hasNext": false, "hasPrev": false }
}
```

---

### POST /pdfs/:id/process

Extract LaTeX content from the uploaded PDF. Text-based PDFs are parsed directly; scanned PDFs go through an additional OCR step before conversion.

**Auth:** Bearer token or API key

```bash
curl -X POST https://api.texer.org/pdfs/pdf_m3k7w1/process \
  -H "Authorization: Bearer YOUR_TOKEN"
```

```json
{
  "id": "pdf_m3k7w1",
  "status": "processed",
  "pages": 12,
  "latex": "\\documentclass{article}\n\\begin{document}\n...",
  "processing_time_ms": 8420
}
```
