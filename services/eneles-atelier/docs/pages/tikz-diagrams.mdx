# TikZ diagrams

Create publication-quality diagrams without writing TikZ code by hand. Eneles offers three ways to work with TikZ.

## Browse the library

Visit the [Library](/library) to explore 50+ categorized TikZ packages with live previews:

- **Graphs**: nodes, edges, trees, forests
- **Automata**: finite state machines, Turing machines
- **Plots**: function plots, bar charts, data visualization
- **Circuits**: logic gates, electrical circuits
- **Chemistry**: molecular structures, reaction diagrams
- **Commutative diagrams**: category theory arrows

Each example includes copyable source code. Click any example to open it in a live preview where you can edit the code and see changes in real time.

## Visual TikZ builder

Open **TikZ Studio** from any project to build diagrams visually:

1. Place nodes by clicking on the canvas
2. Connect nodes with edges (drag from one node to another)
3. Style elements: colors, shapes, line styles, labels
4. Watch the TikZ code update in real time in the code panel
5. Insert the generated code into your project when done

## AI diagram generation

Describe what you want in plain English and let the AI generate TikZ code:

- *"Draw a binary tree with 7 nodes"*
- *"Create a flowchart for a login process"*
- *"Make a state machine with 3 states and transitions"*

The AI generates compilable TikZ code that you can edit and refine.

> **Tip:** For complex diagrams, start with AI generation to get the basic structure, then refine manually in TikZ Studio.
