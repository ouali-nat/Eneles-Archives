# Eneles Atelier

Atelier scientifique de l’écosystème Eneles. Le dossier regroupe le frontend Next.js, l’API NestJS, le compilateur TeX Live et les bibliothèques de documentation, d’apprentissage et de modèles.

- `frontend/` : application d’édition LaTeX/PDF.
- `backend/` : API, sessions, projets, collaboration et base PostgreSQL.
- `compiler/` : service isolé TeX Live.
- `docs/`, `learn/`, `library/` : documentation, parcours et bibliothèque TikZ.
- `impress/`, `mobile/`, `powerpoint/` : composants annexes récupérés du projet source.

Voir [DEPLOYMENT-ENELES.md](./DEPLOYMENT-ENELES.md) pour l’architecture de déploiement. Les avis de licence MIT originaux sont conservés dans chaque composant.
