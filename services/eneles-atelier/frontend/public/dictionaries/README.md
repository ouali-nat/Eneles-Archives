# Spelling dictionaries

Hunspell dictionaries for the editor's spell checker, loaded on demand by
`lib/spell/spell.worker.ts`. Each folder holds the files from the npm package
named below, unchanged, with its license.

| pt | dictionary-pt 4.0.0 (Brazilian Portuguese) | LGPL-3.0 OR MPL-2.0 |
